## 機能
### /udlコマンド
- remove - エンティティを削除する
- removeAll - 全てのエンティティを削除する
- storageRemove - ストレージからエンティティを削除する
- getAllEntities - 全てのエンティティを取得する
- theWorld - 時を止める

### UDL Sword
Shift + 右クリックで設定画面を開く

右クリックで実行
